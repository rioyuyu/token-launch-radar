How the radar works

implied = round( TVL ^ 0.85 × 2 × growth × maturity )

Growth is 1 + clamped 7-day change × 0.75, with the change clamped to −60% … +120% (missing change counts as 0). Maturity is 0.5 + min(age, 1095 days) ÷ 1095 × 0.5, where age is days since first listing (365 days when unlisted). The same function scores every row: no protocol name is hardcoded anywhere, and no row is hand-picked. The farm plan in the detail panel is generated in-page from the row's own category, chains, TVL and age, by the same rules the board program uses — it is a plan template, not a guarantee of a token.
