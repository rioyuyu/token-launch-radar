The model

—

The size curve is fitted on live tokens that already trade: market cap against TVL. A protocol's if-launched value is its TVL through that curve; its implied value is if-launched times its launch odds.

Stepwise held-out backtest

    Each step is scored the same way: fit on the older half of dated live tokens, predict the newer half, report the median miss.
