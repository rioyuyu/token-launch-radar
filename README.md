Token Launch Radar is a program and dashboard that ranks 198 pre-token protocols by implied airdrop value, with a farm plan of step-by-step actions for each protocol. It scores every rankable protocol from the snapshot's own TVL, growth and age figures, and shows the ranked board alongside the protocols that already have a live token.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot>
```

The snapshot is sealed input and is not included in this repo.
